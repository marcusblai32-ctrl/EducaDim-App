EducaDim original UI/UX reference

This is the original standalone HTML prototype supplied earlier in the EducaDim design workflow. Use it as the visual and interaction source of truth when rebuilding the Lovable project.

Important: preserve the layout, navigation, colors, screen structure, cards, interactions, lesson/course flows, flashcards, offline-download demonstration, and floating chat entry point as present in the reference. Do not replace it with a generic LMS template or redesign it independently.

This HTML prototype is for design reference only. Demo offline actions are not real Django downloads. Any real app must later be implemented in Flutter and integrated with the existing Django API.
